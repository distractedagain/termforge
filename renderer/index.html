Connection security

Managed SSH verifies server fingerprints before using credentials and maintains a separate trusted-host list. System OpenSSH uses your known_hosts file. Review new fingerprints through a trusted source. Connections use explicit profile fields; your SSH config file is not loaded. Profile imports do not connect automatically.

Configure Button Bar

Button Bar commands are placed in the Command Window for review. Press Send when ready.

Import & export

Imports are reviewed by the application and do not open connections. Passwords and saved credential references are excluded from imports and exports. Exported files may include hostnames, manually entered usernames, and local key paths.

ForgeCRT

An independent terminal workspace for macOS, Windows, and Linux. Includes managed SSH with protected credentials, System OpenSSH for advanced connections, and a real pseudoterminal for local shells.

Session and transfer tools

The file-transfer workspace browses local and remote folders and copies regular files using SFTP or SCP, with progress and cancellation. Managed SSH prompts privately; System OpenSSH prompts in the terminal. Existing OpenSSH SFTP profiles still open the command-line client. Saved Credentials and Trusted SSH Hosts are available in the Tools menu. Logging captures received terminal output to a local file; avoid recording sensitive output. Raw TCP and Telnet send data without SSH encryption.

Python scripts run with your local user privileges. Run scripts you trust. ForgeCRT provides a documented subset of familiar terminal scripting methods; it does not provide complete SecureCRT script compatibility.
